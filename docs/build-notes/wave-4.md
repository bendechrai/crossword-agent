## T50 determinism fix (outside the workflow)

After T50's first merge was rolled back (offline replay diverged on main), an investigator found the cause: the repair pass read a word list from data/wordlist/collaborative.txt, which is gitignored and only present where npm run wordlist:fetch had been run, and src/validate/wordlist.ts silently substitutes a null word list when it is absent. The fix (commit 7d3d160) adds SolveCommandOverrides.wordlistPath and pins test/fixtures/wordlist.txt in both scripts/fixtures-refresh.ts and test/integration/solve.test.ts, and uncaps wallMs in offline replay; snapshots were regenerated offline (5addcc4). Three fresh-container runs agreed. Known gap carried forward: src/llm/tierRouter.ts sends the reasoning-off parameter only for purpose 'seed', so tier-1 re-ask and repair calls never return JSON and are never cached; all six fixtures therefore replay with --offline-lenient, and the baseline profile's re-ask and repair phases are effectively dead on tier 1 in production. Follow-up: send reasoning-off for every tier-1 call, refresh the cache, regenerate snapshots.
